# Концепция: alexsoft — Personal Ecosystem Lab

## Тип продукта

Персональная мультисервисная платформа — связка лендинга, набора продуктов (mini-SaaS / боты / инструменты), внутренней платформы данных (БД + BI) и AI-агентов. Развёртывается как контейнеризированная система с полным DevOps-циклом.

## Цель

Практическое освоение полного цикла разработки и эксплуатации ПО: идея → код → CI/CD → мониторинг → BI → AI-агенты.

## Ценность

- Личное пространство проектов и полигон для ИТ-инструментов
- Репозиторий-портфолио с артефактами: диаграммы, Terraform, Docker, Grafana dashboards

## Основные функции

1. Публичный лендинг-визитка с портфолио продуктов и живыми демо
2. Несколько независимых микросервисов-продуктов
3. Единая платформа данных: БД, ETL, BI-дашборды
4. Слой AI-агентов (единый шлюз/оркестратор)
5. Инфраструктурный контур: логирование, мониторинг, версионирование, CI/CD
6. Автоматически обновляемая архитектурная документация (C4/UML из кода и конфигов)

## Продуктовые сервисы (начальный набор)

- Лендинг: кнопки перехода в микросервисы и портфолио
- Мини-игры
- RAG
- AI-агент: создание поста, тестировщик, скрипт подстановки ответов в мессенджеры и почту
- Другие микросервисы — по мере появления

## Инфраструктура

Сначала ноутбук (Docker Compose), затем облако и k3s. Домен и DNS — на этапе лендинга.
