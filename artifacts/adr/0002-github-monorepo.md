# ADR-0002: GitHub monorepo

- **Статус:** accepted
- **Дата:** 2026-08-22
- **Контекст:** Платформа — связка лендинга, нескольких продуктов, данных и инфры. Отдельные репозитории усложнят единый CI, диаграммы и портфолио.
- **Решение:** Один GitHub-монорепозиторий. Продукты в `apps/`, общее в `packages/`, инфра в `infra/`, архитектура в `artifacts/`.
- **Последствия:** Единый pipeline и единый C4-workspace. Позже при росте можно ввести path-filters в Actions. Публичность репозитория — решение владельца на GitHub (для портфолио обычно public).
