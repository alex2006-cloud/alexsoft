# US-0001: Узнать о проекте alexsoft у AI-агента

- **Бизнес-кейс:** [Бизнес-кейс 1](../../../CONCEPT.md)
- **Роль:** Пользователь
- **Хочу:** Задать вопросы AI-агенту и получить ответы по проекту alexsoft
- **Чтобы:** Понять, чем проект может быть полезен, не изучая репозиторий
- **Критерии приёмки:**
  - Неавторизованный пользователь открывает лендинг и видит описание проекта, список продуктов и кнопку входа
  - Неавторизованный пользователь пытается открыть агента, но система предлагает войти в систему
  - Неавторизованный пользователь прошёл аутентификацию и авторизацию, и видит список агентов
  - Авторизованный пользователь задаёт Q&A-агенту вопрос о проекте и получает ответ, основанный на материалах проекта
- **Ссылки:** [CONCEPT](../../../CONCEPT.md)
