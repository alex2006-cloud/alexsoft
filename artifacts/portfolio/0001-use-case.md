# UC-0001: Узнать о проекте alexsoft через Q&A-агента

- **Актор:** Пользователь (сторонний пользователь системы)
- **Предусловия:**
  - Система доступна (лендинг открывается)
  - Q&A-агент по проекту развёрнут и доступен авторизованным пользователям
  - Пользователь ещё не авторизован
- **Основной поток:**
  1. Пользователь открывает лендинг.
  2. Система показывает описание проекта, список продуктов и кнопку входа.
  3. Пользователь нажимает «Войти» и успешно проходит аутентификацию.
  4. Система авторизует пользователя и показывает список агентов.
  5. Пользователь выбирает Q&A-агента по проекту.
  6. Система открывает диалог с агентом.
  7. Пользователь задаёт вопрос о проекте.
  8. Система возвращает ответ, основанный на материалах проекта.
  9. Пользователь завершает диалог (или задаёт следующий вопрос — повтор с шага 7).
- **Альтернативные потоки:**
  - 2a. Пользователь без авторизации пытается открыть агента.
    1. Система не открывает диалог и предлагает войти.
    2. Сценарий переходит к шагу 3.
  - 3a. Аутентификация не удалась.
    1. Система показывает сообщение об ошибке и предлагает повторить вход.
    2. Сценарий возвращается к шагу 3 или завершается без доступа к агентам.
  - 8a. Агент не находит ответ по материалам проекта.
    1. Система сообщает, что по имеющимся материалам ответа нет.
    2. Пользователь может задать другой вопрос (шаг 7) или завершить диалог.
- **Постусловия:**
  - Пользователь авторизован в системе
  - Пользователь получил хотя бы один ответ агента по проекту
  - Сессия диалога сохранена
