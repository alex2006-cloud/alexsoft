Контракт Business Logic (apps/api) — кабинет, реестр агентов, запуски, админка.

Контракт-первый (contract-first) для сервиса apps/api (FastAPI). Источники: ADR-0019 (кабинет SSR/BFF, JWT проверяет FastAPI), ADR-0020 (локальная топология), artifacts/architecture/c4-l1-l2-l3.dsl.

Потребитель

Единственный клиент — BFF кабинета (apps/cabinet). Браузер в BL напрямую не ходит, BL наружу не публикуется.

Безопасность

Authorization: Bearer <JWT Authentik>. FastAPI проверяет подпись по JWKS Authentik, iss, aud (client_id приложения alexsoft-cabinet), exp. Роль выводится из claim groups: alexsoft-users → user, alexsoft-admins → admin (admin включает права user). Nginx JWT не проверяет.

Агенты

Реестр агентов лежит в BL (bl.agents). Тип запуска (kind): echo (заглушка без LLM), langgraph (LangGraph Agent Server). Агент БП1 добавляется записью в реестр — контракт не меняется.

Запуски и квота

POST /v1/agents/{agentId}/runs создаёт запуск и сразу отвечает 202. Ход выполнения — Server-Sent Events GET /v1/runs/{runId}/events (повтор с начала + продолжение до done/error). На пользователя действует суточная квота запусков; при превышении — 429.

Соглашения

  • Версия в пути: /v1. Время — RFC 3339 UTC. Идентификаторы запусков — UUID.
  • Ошибки — application/problem+json (RFC 9457).
  • Корреляция: X-Request-Id принимается и возвращается.
